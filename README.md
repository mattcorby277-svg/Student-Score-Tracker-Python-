# Student-Score-Tracker-Python-
A beginner‑friendly Python program that collects student names and scores, validates input, prevents duplicates, calculates the class average, and displays results in a clean format. This project demonstrates core Python fundamentals including loops, conditionals, dictionaries, lists, boolean logic, and error handling.

-----

Features
--
Enter any number of students

Prevent duplicate student names

Validate score input (must be between 0–100)

Handle invalid input using try/except

Store student names and scores in a dictionary

Track all scores in a list

Calculate class average

Display each student’s result (name, score, pass/fail)

--------

What This Project Demonstrates
-
This project covers all essential beginner Python syntax:

Variables

Input & Output

While loops

Nested loops

Conditionals (if/else)

Dictionaries

Lists

Boolean logic

Error handling (try/except)

--------------

The program flow:
-----

Ask how many students will be entered

Loop until all students are processed

For each student:

Ask for a name

Prevent duplicates

Ask for a score

Validate score range

Store data

Display result

After all students are entered, calculate and print the class average

Formatted printing (f‑strings)
